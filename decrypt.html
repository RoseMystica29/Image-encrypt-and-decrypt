Secure Image Encryption for WhatsApp Sharing

AES-GCM encryption with optional pixel scrambling. Send the .enc file as a WhatsApp document and share the key separately.

Encrypt an image

Recommended
Encryption is AES-GCM; scrambling adds a reversible layer before encryption.
Send on WhatsApp: Open WhatsApp ➜ attach ➜ Document ➜ choose the .enc file from Downloads/Files. Share the key in a separate message.

Decrypt received .enc file

Recipient steps: Open this page ➜ select the .enc file you received ➜ enter the key ➜ decrypt to restore the original image.
Files use AES-GCM with PBKDF2-derived keys. The .enc embeds salt, iv, MIME, original name, and whether pixel scrambling was used.
